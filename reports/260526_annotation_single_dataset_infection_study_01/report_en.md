## Important Limitation

This 260526 report is an intermediate review generated from v11 evidence containers. For four datasets, the upstream workflow first reduced the original gene space to 8,000 pre-HVG genes and then to an approximately 4,000-gene analysis X/HVG space. Therefore, marker-gene availability alerts in this report mean absence from the v11 analysis container, not necessarily absence from the original data. Markers such as FOXP3/IL2RA/CTLA4 are present in the original processed H5AD for several datasets but were dropped from the analysis container. Final submission-quality interpretation requires regenerating CellTypist, marker scoring, and marker availability from the original all-gene input.

## Dataset-Specific Assessment

- Overall: 54,924 cells / 33,538 original processed genes / 8,000 pre-HVG genes / 3,961 analysis X/var genes. Parent/Blood residual is low at 193 cells (0.004), median confidence is 0.819, and source disagreement is moderate at 7,791 cells (0.142).
- More reliable regions: Classical Monocyte, NK Cell, Naive B Cell, Non-Classical Monocyte, and Platelet have relatively strong source agreement and are interpretable as major lineage-level calls.
- Main caveat: `Doublet` accounts for 981 cells and artifact-like cells for 1,340 cells. These are retained as explicit submitted states rather than filtered out, so mixed-lineage marker UMAPs and scrublet evidence should be reviewed.
- Marker availability: Treg lacks FOXP3/IL2RA/CTLA4 and only retains TIGIT, so Treg-level interpretation is not well supported. Memory B/ABC and Plasma/ASC marker availability is also limited, so B-cell fine boundaries should remain confidence-capped.
- Source disagreement: CD4 T Effector Memory (0.327), CD8 Cytotoxic / T Effector Memory (0.201), and Memory B Cell (0.225) are the main review targets. Broad lineage is relatively stable; fine T/B labels require marker and disagreement review.
