## Dataset-Specific Assessment

- Overall: 43,767 cells / 3,933 X/var genes / 8,000 raw genes. Parent/Blood residual is 529 cells (0.012), but source disagreement is elevated at 11,680 cells (0.267).
- More reliable regions: Classical Monocyte, NK Cell, Plasma Cell, Non-Classical Monocyte, pDC, Platelet/RBC are comparatively coherent. Plasma Cell is not fully weak despite JCHAIN missing, because MZB1/XBP1/PRDM1/IRF4/IGHG1/IGHA1 remain available.
- Main weakness: Memory B Cell has disagreement 0.724 and Naive B Cell 0.392, making the naive/memory B boundary the highest-priority review issue. Remaining markers such as CD27, ITGAX, TBX21, and BANK1 should be checked in UMAP and dotplot views.
- T-cell caveat: CD4 Naive/Tcm and CD8 Cytotoxic/Tem show disagreement 0.37/0.34. Treg has 554 cells but lacks FOXP3/IL2RA/CTLA4 and shows disagreement 0.702, so it should be treated as a provisional confidence-capped fine label.
- Interpretation: The main issue is fine B/T label disagreement rather than broad lineage failure. Confidence capping based on marker availability, subcluster coherence, and source disagreement is preferable to study-specific hard-coding.
